# build-2611-10 · 주간업무보고 (v2 · 심플형)

생성형 AI 업무자동화 전문가과정 **2차수** 수강생 프로젝트 10 — 기획 김수준.

**바로 쓰기: https://build-2611-10.jobability.co.kr/**

> 2026-11-12: 기획자의 [수정요청](심플형)에 따라 다시 만들었습니다. 예전 판 v1.1(지난주 보고서와 비교 · 분야별 보고서)은 **17번** https://build-2611-17.jobability.co.kr/ 으로 옮겨 그대로 있습니다.

팀원들의 엑셀 주간업무보고를 올리면 날짜 · 주요내용 · 마감일 · 세부내용을 원문 그대로 취합해 금주 · 차주로 나누고,
진행 · 완료 · 지연과 의사결정 필요 항목을 대시보드로 보여 줍니다. 메뉴는 네 개, 자료는 브라우저(localStorage)에만 저장됩니다.

| 파일 | 역할 |
|---|---|
| `js/weekly.js` | 엔진 — 날짜 읽기 · 머리글로 4개 항목 추출 · 주 배치 · 상태(지연 계산) · 중복 의심 · 보고서 표. **규칙은 전부 여기** |
| `js/app.js` | 화면 4개(대시보드 · 주간업무 현황 · 엑셀 업로드 · 보고서 및 이력)와 저장 |
| `css/weekly.css` | 도구 화면(네이비 사이드바). `css/style.css` · `css/app.css` 는 사용법 · 기획서 페이지용 |
| `proto/` | 기획자가 만든 시제품(참고용 원본) |
| `samples/` | 엑셀 양식 · 가짜 예제 |
| `test/` | 규칙 테스트 `node test/logic.test.js` · 화면 테스트 `node test/smoke.browser.js` |

저장 구조(`tasks` · `logs`)는 추후 Supabase 표로 옮기기 쉽게 납작하게 두었습니다 — `js/weekly.js` 첫머리 참고.
